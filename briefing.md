Promise API

Promise.all: Resolves only when all input promises resolve; rejects immediately if any input promise rejects.
![Promise.allThingInJS](images/promisedot%20all%20thing%20in%20js.jpeg)



_______---__________----------------------------------------------
Promise.allSettled: Resolves when all input promises have settled (either resolved or rejected); never rejects.
